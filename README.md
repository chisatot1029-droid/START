# スターと（縦スクロール版 プロトタイプ）

田野さんの Figma（images フォルダの書き出し画像）を もとに作った版です。
`index.html` をダブルクリックすると、PCの Chrome / Edge で遊べます。

## 操作
- ↑ ↓ ← →（または W A S D）：あるく
- iPad：ゆびで なぞる … なぞった 向きに あるく（はなすと 止まる）
- クリック / タップ / Enter / スペース：セリフを すすめる
- 選択肢：クリック（または 数字キー 1・2・3）

## ファイル
| ファイル | 中身 |
|---|---|
| `js/story.js` | セリフ・選択肢・できごとの順番（書き方は先頭のコメント。Figma のフレーム番号つき） |
| `js/game.js` | 移動・カメラ・会話・演出の しくみ |
| `style.css` | 会話ウィンドウ・ボタン・タイトルの見た目（Figma の位置と色に あわせてある） |
| `assets/` | Figma の画像から 切り出した素材 |

## まだ デザインがない所（仮で つないでいる所）
- 「主人公の一人称の動画」（9）→ まぶたが ひらく演出で 代用
- バケモノが 人を 食べる場面（62・63）→ 絵を「バケモノだけ」に 切りかえるだけ
- 「止めない」を えらんだあと → 時計が 鳴りつづけ、もう一度 えらぶ
- 荷物（カセットテープ／CDプレイヤー／ヘッドホンのコード）を えらんだあと → 「つづく」画面
- タイトルの背景、セッティング画面
